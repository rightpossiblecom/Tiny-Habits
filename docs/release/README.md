# Tiny Habits - Release Bundle

This bundle contains all necessary assets for the production release of Tiny Habits.

## Contents
- `tinyhabits-release.jks`: The Android release keystore (CRITICALLY IMPORTANT - DO NOT LOSE).
- `key.properties`: Signing credentials containing the passwords for the keystore.
- `play_store_listing.md`: Official copy for the Play Store.
- `privacy_policy.md`: Official Privacy Policy to be hosted online.
- `featured_graphic_tinyhabits.png`: The 1024x500 App feature graphic.

## Important Note
The `tinyhabits-release.jks` file is required to release any future updates to the app on the Google Play Store. It must be kept secure. Do not commit this release folder to a public repository!
